# Карта кодової бази — `app/`

## 1. Як агент будував карту

- Інструмент / модель: Gemini 3.1 Pro (High) - Antigravity Agent
- Промпт (дослівно або стисло): Самостійне виконання таски агентом з використанням інструментів командного рядка (run_command) і читання файлів (view_file).
- Вартість навігації: 11 викликів інструментів (пошуки, читання файлів, запуски тестів).
- Він прочитав усе підряд чи шукав? Агент (тобто я) шукав конкретні речі: спочатку запустив тести, перевірив `package.json`, вхідні файли `app/bin/` і `server.js`, провів пошук використання форматування (`grep -r formatDate`), проаналізував залежності від `format.js` та перевірив `store.js`.

## 2. Карта (те, що видав агент, з вашими правками)

### Точки входу

| Точка входу | Що запускає | Файл |
|---|---|---|
| HTTP | Express-подібний сервер (самописний роутер), обробка API та сторінок | `app/server.js` |
| CLI / cron | Нічний експорт даних для бухгалтерії | `app/bin/nightly-export.js` |
| CLI / cron | Розсилка нагадувань про оплату рахунків | `app/bin/send-reminders.js` |
| CLI | Рендер рахунків, фікси, звіти, імпорт виписок | `app/bin/*.js` |

### Дані

Зберігаються як JSON-файли у теці `app/data/` (напр., `customers.json`, `invoices.json`). 
- **Дати**: зберігаються у форматі ISO 8601 `YYYY-MM-DD` (рядки). 
- **Гроші**: зберігаються та обробляються у цілих копійках (цілі числа).

### Зовнішні інтеграції

- **Бухгалтерська система ("Облік-Плюс")**: споживає щоденні експорти у форматі CSV (`out/export/`), генерується через `lib/export/accounting.js`. Залежить від формату дат і грошей, що очікує бухгалтерська система.
- **Поштові нагадування**: скрипт `send-reminders.js` пише повідомлення (листи) у вигляді файлів до теки `app/out/mail/`.
- (Раніше) pdf-render: сервіс рендерингу PDF (зараз відключений, `lib/legacy`).

## 4. Висновок

Як і очікувалось для старого легасі проєкту, документація частково застаріла (`ARCHITECTURE.md` говорить про Express, MongoDB та Handlebars, що вже не відповідає дійсності). Дані перенесені в JSON, зовнішніх залежностей немає, а PDF-рендеринг відключений з 2020 року. Я (агент) перевірив найризикованіші твердження зі старої документації, порівнявши їх із фактичним кодом (напр. `server.js`, `store.js`), щоб не будувати план на застарілих фактах.
